## 失败处理

预检或备份阶段失败，不改变配置与进程。开始修改开关后的失败会尝试只停止 C++ 后端，核对 `.env` 没有被其他人修改，再恢复原字节和只读运行。不能确认恢复时会明确提示；如只读启动失败，则尝试保持 C++ 停止，不动原站。

自动恢复只恢复配置和 C++ 服务，不还原数据库、不删除已经保存的作品，不恢复或覆盖 PM2 全局保存记录。请发回本轮日志和 `pm2 list`，不要反复执行启用命令或还原旧数据库。SIGKILL、断电、磁盘损坏等不能保证自动恢复，需要结合私有备份人工核查。
